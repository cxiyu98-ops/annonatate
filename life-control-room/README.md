# 人生后台 / Life Control Room

纯 HTML、CSS、Vanilla JavaScript 桌面优先单页原型，无框架、后端、登录或外部资源依赖。

## 本地运行

直接打开 `index.html`。无需构建。部分浏览器对 file:// 的 localStorage 支持有所不同；若保存受限，页面底部会提示。

推荐使用本地 HTTP：在此目录执行 `python3 -m http.server 8000`，访问 http://localhost:8000 。GitHub Pages 可直接发布此目录内容，所有链接均为相对路径。

## 文件与修改位置

- `index.html`：三屏布局、各模块容器、屏幕内编辑器。调整面板结构或添加未来模块，从这里开始。
- `styles/main.css`：视觉和响应式布局。顶部 `:root` 包含配色变量；`.control-room` 控制三屏比例，媒体查询控制小屏堆叠。
- `scripts/state.js`：`LCR.seed()` 中编辑示例内容。统一状态模型、localStorage 键、来源引用、活动记录。
- `scripts/ui.js`：各模块渲染和编辑字段。未来模块在 `render()`、`open()` 中增加对应渲染与编辑。
- `scripts/timer.js`：25 分钟专注计时，开始、暂停、重置与刷新恢复。
- `scripts/app.js`：事件与产品流程，包括任务 CRUD、同步完成、休息模式、导航。
- `assets/icons/`、`assets/images/`：预留本地素材目录。现有城市背景与装饰由 CSS 绘制。

## 保存与计时

全部状态保存到当前浏览器当前来源的 localStorage，键为 `life-control-room.v1`。每次有效修改自动保存；同一来源刷新恢复。不同浏览器、端口或 GitHub Pages 来源不共享数据。

当前任务存储来源类型和 ID，避免复制任务造成完成状态不同步。设为当前任务会暂停已有计时；完成任务同步原条目、记录活动并清空当前任务。收集项设为当前任务会先转为今日要事。下一步返回计划台会移入今日要事。

运行中的计时器保存剩余时间快照与开始时间戳，用墙钟时间计算刷新后的剩余秒数。离开页面不停止计时；进入休息模式暂停计时和当前任务。退出休息模式不会自动启动。

休息选项用于选择本次休息的类型，不播放音频或增加额外倒计时。主线重置进度会把编辑器进度改为 0，点击保存后生效。活动记录最多保留 100 条。

示例内容只在没有本地状态时加载；修改种子后可在开发者工具删除上述存储键并刷新，以查看新种子。无清空数据按钮，避免增加规格外功能。

## 三屏交互层级（本次修订）

- Level 0：三屏总览。仅展示有限条目的模块摘要；点击模块进入所在屏幕的详情。
- Level 1：模块详情。该屏幕展示完整列表与原有操作，`← 返回总览` 返回；其他屏幕保留浏览位置。
- Level 2：点击条目后在所属屏幕内编辑，不使用遮挡其他屏幕的弹窗。返回或取消不保存，保存后回到模块详情；Escape 返回一层。
- 各屏幕可以独立展开和编辑，未保存草稿留在原屏幕；点击全局「首页」关闭编辑并返回三屏总览。
- 浏览层级与未保存草稿仅存在内存中；原有业务数据的 localStorage 键和结构不变。
- `scripts/screens.js`：分层导航、独立屏幕视图和编辑器实例，以及模块摘要渲染。
- `styles/room.css`：本次显示器外观、首屏尺寸、摘要和屏幕内详情样式；覆盖并复用原有 `main.css`。
- `assets/images/night-city.svg`：本地像素城市背景，不请求外部素材。
